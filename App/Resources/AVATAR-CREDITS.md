# Avatar credit

## Default dragon

The default character, `AitvarasDragonRuntime.glb`, is built from a dragon master
generated with [Meshy](https://www.meshy.ai) and then refined and posed in Blender
for Aitvaras. `scripts/build-dragon-runtime.py` reduces that master to the
real-time asset. It is therefore not fully hand-authored. See
`docs/character/dragon-runtime/` for how it was made and checked.

## Authored fallback dragon

`AitvarasDragon.glb` is used only if the default is missing. It is an original
authored mesh
generated by `scripts/generate-dragon-avatar.py`. It contains 24,452
triangles across 74 named mesh parts: sculpted skull and snout, overlapping
head/body/limb scales, layered belly and face armour, curved jointed limbs,
separate paws and claws, multi-panel wings with finger bones, a curled tail,
and a two-layer emissive flame. Named nodes keep the head, eyes, jaw, wings,
cheeks, tongue and flame independently animatable in SceneKit.

This fallback asset and its generator were created for Aitvaras and contain no
third-party model geometry or textures.

## Optional human avatar

`AitvarasAvatar.glb` originates from
[`avatars/brunette.glb`](https://github.com/met4citizen/TalkingHead/blob/main/avatars/brunette.glb)
in Mika Suominen's MIT-licensed
[TalkingHead](https://github.com/met4citizen/TalkingHead) project. It is a
Ready Player Me-generated character with ARKit and Oculus viseme blendshapes.
Aitvaras uses those blendshapes for blinking, expressions and voice-driven lip
sync.
